# Dogfooding `vas`, 2026-10-16 — the Me35 rental (three RTX 5090s, askesis)

The first real use: three boxes rented for askesis's Me35 (California, Poland, Belgium), a read-only key
(`vastai-skopos`: User Read + Instances Read, no Write, no 2FA).

## Found in the first minute

1. **The account endpoint redirects.** `GET /api/v0/users/current` answers **301**; `vas` follows no redirect
   (a design rule: the key is never re-sent), so the money line read `credit ?`. The official CLI's HTTP library
   follows redirects silently. Fix: request the canonical `/api/v0/users/current/`. Credit then read $30.38.
2. **The API's `ssh_port` is not always the port to connect to.** One box read `ssh_port` 37240 while the
   dashboard's own command used 37241. The official CLI's `_ssh_url` adds 1 on the proxy for Jupyter-launched
   instances (`image_runtype` contains `jupyter`), and prefers a directly mapped `22/tcp` when present. Fix: the
   proxy rule, with the field read and a doctest.
3. **Key file saved by Notepad as `vast_api_key.txt`.** The README warns about it; `vas` could say so too:
   when the file is absent but `<name>.txt` exists, name it in the error.

## What helped

- The whole fleet in one table with per-box cost so far and the burn rate, before any ssh.
- `credit $30.38 | burn $1.940/h over 3 running | ~15.7 h left at this rate`: the runway number is the one to watch
  on a budget.
